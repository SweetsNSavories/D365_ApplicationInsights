# platform-traces/

Generic `traces`-table TSG skeleton — applies to any Power Platform component whose SDK emits to the App Insights `traces` table.

## Files

| File | What it does |
|---|---|
| [`template-tsg-traces-skeleton.kql`](template-tsg-traces-skeleton.kql) | Parameterised `traces` lookup with `severityLevel`, `cloud_RoleName`, time filters — fill in the parameters and run |
