Pulse & Health

01

Anomaly pulse — requests/min, last 24 h

anomaly

Watch: a marker on the line = a real anomaly relative to the 24 h baseline. Daytime hump should look smooth; markers in the trough usually mean a scripted burst. 

// Pulse — requests per minute, last 24 h. Markers = real anomalies vs current baseline.
let _step = 1m;
requests
| where timestamp > ago(24h)
| make-series Calls = count() default = 0
    on timestamp from ago(24h) to now() step _step
| extend (anomalies, score, baseline) = series_decompose_anomalies(Calls, 2.5, 0, 'linefit')
| extend anomaly_points = series_multiply(Calls, anomalies)
| render timechart
02

Hourly request volume — last 7 days

volume

Watch: weekday peaks ~3–5× weekend. Event-day surge should be visible without disappearing the prior baseline. 

// Hourly request volume — last 7 days. Should follow weekday business-hour pattern.
requests
| where timestamp > ago(7d)
| summarize Calls = count() by bin(timestamp, 1h)
| render timechart with (title = 'Requests/hour — 7d', ytitle = 'Calls')
03

Failure rate % per hour — last 7 days

errors

Watch: anything ≥ 2–3× the prior week's typical band. Sustained > 1 % on a Dataverse-backed env usually means something real. 

// Failure rate % per hour — last 7 days.
requests
| where timestamp > ago(7d)
| summarize Total = count(), Failed = countif(success == false) by bin(timestamp, 1h)
| extend FailurePct = round(100.0 * Failed / Total, 2)
| project timestamp, FailurePct
| render timechart with (title = 'Failure rate % — 7d')
04

4xx vs 5xx per day — last 14 days

errors

Watch: 5xx growing day-over-day = server-side regression. 4xx growing = client / auth / throttling. 

// 4xx vs 5xx per day — last 14 days. Stacked to see error-class composition.
requests
| where timestamp > ago(14d)
| where toint(resultCode) >= 400
| extend Class = case(toint(resultCode) >= 500, '5xx',
                      toint(resultCode) >= 400, '4xx',
                      'other')
| summarize Errors = count() by bin(timestamp, 1d), Class
| render columnchart with (kind = stacked, title = '4xx / 5xx per day — 14d')

06

Top 10 operations by call volume — daily, 14 days

workload

Watch: a new operation muscling in = new feature traffic / integration. A line going flat or dropping = something stopped calling. 

// Top 10 operations by call volume — daily, last 14 days. Shows workload composition.
let _top = requests
    | where timestamp > ago(14d) and operation_Name !contains "synapse"
        and operation_Name !contains "GetClientMetadata" and operation_Name !contains "WebResources"
        and operation_Name !contains "datalake"           and operation_Name !contains "CDNHandler"
        and operation_Name !contains "/Organization.svc/web"
        and operation_Name !contains "WhoAmI"             and operation_Name !contains "ClientMetrics"
        and operation_Name !contains "usersettings"
    | summarize n = count() by operation_Name
    | top 10 by n
    | project operation_Name;
requests
| where timestamp > ago(14d)
| where operation_Name in (_top)
| summarize Calls = count() by bin(timestamp, 1d), operation_Name
| render areachart with (kind = stacked, title = 'Top 10 ops — daily volume, 14d')

Daily Active Users by channel — 30 days

audience

Watch: Power Pages jumping during an event = public surge. MDA flat or shrinking = agent capacity not scaling — that's a staffing signal, not a perf one. 

// Daily Active Users split by channel — 30 days. PowerPages = public/citizens, MDA = internal/agents.
pageViews
| where timestamp > ago(30d)
| extend cd        = parse_json(customDimensions)
| extend portalId  = tostring(cd.PortalId)
| extend appModule = tostring(cd.appModule)
| extend channel   = case(isnotempty(portalId),  'PowerPages',
                          isnotempty(appModule), 'ModelDrivenApp',
                          'Other')
| summarize DAU = dcount(user_Id) by bin(timestamp, 1d), channel
| render timechart with (title = 'DAU by channel — 30d')
09

Exceptions — Signal vs Noise (14 days)

signal

Watch: Signal line rising = real new issue, drill in. Noise rising = ignore (or revisit the filter if the gap closes). 

// Exceptions split into Signal vs Noise (PrvRead / PrincipalPrivilegeDenied on first-party entities).
let _IsNoise = (msg:string, ent:string) {
       (msg has "PrvRead" or msg has "prvRead" or msg has "0x80040220")
    or  msg has "SecLib::"
    or  msg has "PrincipalPrivilegeDenied"
    or ((ent startswith "msdyn"     or ent startswith "adx_"
      or ent startswith "msdyncrm_" or ent startswith "msdyn365_"
      or ent startswith "mscrm_")
        and (msg has "Principal"   or msg has "privilege"
          or msg has "Access"      or msg has "denied"))
    or  msg has "was cancelled"
    or  msg has "OperationCanceled"
    or  msg has "TooManyRequests"
};
exceptions
| where timestamp > ago(14d)
| extend cd     = parse_json(customDimensions)
| extend entity = tostring(cd.entityName)
| extend Bucket = iif(_IsNoise(outerMessage, entity), 'Noise', 'Signal')
| summarize Count = count() by bin(timestamp, 1d), Bucket
| render areachart with (kind = stacked, title = 'Exceptions — Signal vs Noise, 14d')

Portal · Bots · Users · Throttle

11

Top Power Pages portal URLs — 7 days

portal

Watch: what citizens are actually loading. New URLs appearing in the top 25 during an event = the form / status page everyone is hitting. High P95ms + high Hits = priority to fix. 

// Top 25 Power Pages portal URLs by hit count — 7d, with users and P95.
// Filters to PortalId-tagged pageViews so MDA noise doesn't leak in.
pageViews
| where timestamp > ago(7d)
| extend cd       = parse_json(customDimensions)
| extend portalId = tostring(cd.PortalId)
| where isnotempty(portalId)
| extend page = coalesce(tostring(name), tostring(url))
| summarize Hits   = count(),
            Users  = dcount(user_Id),
            P50ms  = percentile(duration, 50),
            P95ms  = percentile(duration, 95),
            Errors = countif(itemType == "pageView" and toint(customDimensions.statusCode) >= 400)
        by page
| top 25 by Hits desc
| project page, Hits, Users, P50ms, P95ms, Errors
12

User-agent split: browsers vs bots / scripted — 24 h

bots

Watch: any non-Browser bucket above a few % of traffic = scripted load. Bot/Crawler spike during an event = scrapers piling on; Scripted = an integration / API client. Cross-check with Q13 to find the user, Q14 to see if they're getting throttled. 

// Traffic split by user-agent class — last 24h, 15-min bins.
// Uses raw UA from customDimensions if present, else falls back to App Insights'
// parsed client_Browser (which is just "Chrome 120" etc and won't say "bot").
let _classify = (rawUA:string, browser:string) {
    let ua = iif(isnotempty(rawUA), rawUA, browser);
    case(
      isempty(ua),                                                                           'NoUA',
      ua matches regex @"(?i)bot|crawler|spider|slurp|scrap|facebookexternalhit|googlebot",  'Bot/Crawler',
      ua matches regex @"(?i)curl|wget|python|java/|okhttp|go-http|httpclient|postman|insomnia|axios|node-fetch|powershell|ruby|perl",  'Scripted',
      ua matches regex @"(?i)headless|phantomjs|puppeteer|playwright|selenium|webdriver",    'Headless',
      ua startswith "Mozilla"
        or browser has_any ('Chrome','Firefox','Edge','Safari','Opera','Internet Explorer'), 'Browser',
      'Other')
};
requests
| where timestamp > ago(24h)
| extend cd    = parse_json(customDimensions)
| extend rawUA = coalesce(tostring(cd.userAgent),
                          tostring(cd["User-Agent"]),
                          tostring(cd["user-agent"]),
                          tostring(cd["Http.UserAgent"]))
| extend Bucket = _classify(rawUA, tostring(client_Browser))
| summarize Calls = count() by bin(timestamp, 15m), Bucket
| render timechart with (title = 'Requests by UA bucket — 24h')
13

Heaviest authenticated users — 24 h (top 20)

abuse

Watch: a single uid driving > 5 % of total traffic = a runaway integration or an agent script. High Failed share = that user is also getting 429s / errors (likely throttling — see Q14). Empty uid rows are pre-auth / anonymous portal traffic. 

// Top 20 users by request volume — 24h. Use AuthenticatedId (Entra/AAD oid)
// where present, else session user_Id. Shows % of all traffic so you can spot
// a single account behaving like a fleet.
let _total = toscalar(requests | where timestamp > ago(24h) | count);
requests
| where timestamp > ago(24h)
| extend uid = coalesce(user_AuthenticatedId, user_Id)
| where isnotempty(uid)
| summarize Calls  = count(),
            Failed = countif(success == false),
            R429   = countif(toint(resultCode) == 429),
            Ops    = dcount(operation_Name),
            P95ms  = percentile(duration, 95)
        by uid
| extend PctOfTotal = round(100.0 * Calls / _total, 2)
| top 20 by Calls desc
| project uid, Calls, PctOfTotal, Failed, R429, Ops, P95ms
14

429 throttling by top operation — 7 days

throttle

Watch: a single operation dominating the stack = a client hammering one endpoint and getting bulkhead-throttled (typical Dataverse UserBulkhead pattern). Pair with Q13 to identify which uid is responsible, and Q12 to check if it's scripted UA. 

// 429s per hour by top operation — 7d. Top-5 operations on their own series,
// everything else collapsed into 'Other'.
let _top429 = requests
    | where timestamp > ago(7d) and toint(resultCode) == 429
    | summarize n = count() by operation_Name
    | top 5 by n
    | project operation_Name;
requests
| where timestamp > ago(7d)
| where toint(resultCode) == 429
| extend op = iif(operation_Name in (_top429), operation_Name, 'Other')
| summarize Throttled = count() by bin(timestamp, 1h), op
| render timechart with (title = '429s per hour by top operation — 7d')
